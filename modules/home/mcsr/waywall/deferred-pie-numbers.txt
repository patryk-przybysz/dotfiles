Pie number mirrors (%, mapless, glowdar)
========================================

Absolute src/dst only in settings.lua. Stable strips: rows @ src.y + i*row_step.

tall_pie           preemptive          src/dst absolute (covers thin native pie)
percent            thin + preemptive   thin_src / tall_src + blockentities / unspecified dst
mapless            fullscreen + thin   normal / thin { src, dst }
glowdar            fullscreen only     src + dst (same spot as mapless.normal.dst)

Tune: edit x/y/w/h in settings.lua → nh home switch → relaunch MC.
